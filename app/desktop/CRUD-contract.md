# 影知工坊：本次管理能力与验收边界

## 用户目标

个人使用本地 Windows 桌面软件，将选中的视频变为可核对、可修改、可保留的知识。日常使用不能被旧任务占满，也不能只有能点的按钮、没有保存和恢复能力。

## 本轮实现范围

1. 学习目标仍在第一步输入和修改；新搜索启动新一轮操作区，保存成果留在资料库。
2. 博主、作品：新增链接、修改个人显示名称、全选、取消全选、移出所选。来源链接修改采用新增，不冒充原作者数据。
3. 文字稿：查看、校正、保存、导出。原始机器文字稿不修改，总结使用校正副本。
4. 知识：新增个人笔记、编辑正文和标题、人工标记审核、搜索、导出。
5. 资料库与回收站独立窗口。关闭并重新启动后可查保存资料，但不自动填入五步工作区。
6. 回收站恢复保留正文和审核状态；不提供永久销毁，不删除视频、登录、模型文件。
7. 从现有下载摘要和知识目录索引显式导入既有成果。不递归扫描整盘，不声称索引之外的全部历史已导入。
8. 重复生成不覆盖已保存管理副本；最新机器知识稿可在编辑器中显式载入，确认保存后生效。

## 数据与异常规则

- 唯一管理副本：运行目录下 data/workbench-library/records.json，保存每次修改前的版本；原始生成文件仍为来源证据。
- 保存采用临时文件后原子替换，跨进程锁和 revision 防覆盖。进程崩溃遗留锁不擅自抢占，报可解释错误。
- 文字稿修改使关联知识稿回到待审核并提示来源变化；人工审核不是 AI 自动判断事实正确。
- 空值、越界、重复提交、来源不匹配、保存失败、回收站条目编辑必须显式阻断，不吞掉错误。
- 清空工作区不等于删除资料库；取消选择不等于移出列表；移入回收站不等于删除原始文件。
- 当前仍为本机开发运行包，不据此承诺无语言环境电脑可运行。

## 验收矩阵

| 层次 | 核查内容 |
| --- | --- |
| 数据规则 | 新增/编辑/搜索/删除/恢复/历史/重启/并发/损坏保护 |
| API | 当前任务边界、CSRF、数量边界、编辑稿总结、部分失败、重试 |
| 桌面交互 | 实际控件点击、保存回读、取消确认、输入保留、10条布局、资料库窗口 |
| 工程回归 | 既有上下游测试、配置和脚本语法、原生构建 |
| 外部闭环 | 抖音账号验证、真实下载、实际语音转写、真实模型总结另列证据 |

离线夹具只验证本地调用链，不代表抖音实时可用或模型质量已通过。独立审查和测试记录不足时不通知用户正式验收。
