# 发布门禁

## 源码仓库

- [ ] 敏感信息扫描无真实凭据
- [ ] 运行数据和构建产物未被 Git 跟踪
- [ ] 第三方许可证、固定提交和原创边界清晰
- [ ] Node 与 Python 源码回归通过
- [ ] README 的能力、限制和安装步骤与当前版本一致

## Windows 安装包

- [ ] 在空白 Windows 10/11 环境完成安装
- [ ] 首次启动、登录、搜索、选择、下载、转写、总结和资料库归档闭环通过
- [ ] 取消、超时、验证码、网络失败和重复操作均有中文解释
- [ ] 安装包不携带账号状态、用户数据或模型密钥
- [ ] SHA-256、版本号、回滚包和发布说明齐全

在全部门禁通过前，只能发布源码预览版，不能宣称安装包已达到开箱即用标准。
